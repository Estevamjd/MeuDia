## Tarefa
1. `packages/database/migrations/005_contas_pagar.sql`:
   - `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` em `assinaturas` (`categoria`, `lembrete_dias_antes`) e `preferencias_agente` (`notif_contas_pagar`, `lembrete_dias_antes`);

   - `CREATE OR REPLACE FUNCTION public.pagar_conta(p_conta_id uuid, p_pago_em date DEFAULT CURRENT_DATE, p_banco text DEFAULT NULL) RETURNS public.contas_pagar`: `LANGUAGE plpgsql SECURITY INVOKER SET search_path = public`, `SELECT ... FOR UPDATE`, `RAISE EXCEPTION` se não estiver `pendente`, INSERT em `transacoes` (`automatico=true`), UPDATE da conta;
