## Tarefa
`contas_pagar` é só a definição; nada é gravado por mês. Ocorrência e situação são derivadas da definição + `pagamentos_conta` da competência (`YYYY-MM`).
1. Em `@meudia/shared`, função pura `ocorrenciaDaConta(conta, competencia): { vencimento } | null` (SPEC 5.2): `mensal` ativa todo mês; `anual` ativa só se mês = `mes_vencimento`; `unica` só na competência de `data_vencimento`; recorrente nada antes da competência de `created_at`; `vencimento = vencimentoNoMes(...)`. O cron (BE-07) reusa.
2. `services/contas-pagar.service.ts` (exportar no barrel):
   - `listarContasDoMes(userId, competencia)` → `OcorrenciaConta[]` (`conta`, `competencia`, `vencimento`, `situacao: 'pendente' | 'vencida' | 'paga'`, `pagamento | null`), derivada com `hojeSP()`; inclui contas inativas que tenham pagamento na competência;
   - `obterContaDoMes(userId, id, competencia)` → ocorrência + histórico (`findByConta`);
   - `criarConta(userId, data)`, `atualizarConta(userId, id, data)` (não mexe em pagamentos), `desativarConta(userId, id)` (`ativo=false`);
   - `pagarConta(userId, id, data)` → `pagarContaSchema.parse` (com `competencia`) + `rpcPagar`; `desfazerPagamento(userId, id, competencia)` → `rpcDesfazer`.
Aceite `hojeISO` opcional (default `hojeSP()`) para os testes.
