## Tarefa
Crie `services/contas-pagar.service.ts` e exporte no barrel:
- `gerarContasDoMes(userId, ano, mes)`: assinaturas ativas `mensal` (todo mês) e `anual` (só se `mes === mes_vencimento`), `vencimento = vencimentoNoMes(...)`, `competencia = competenciaDe(vencimento)`, ignora meses anteriores ao `created_at`; chama `upsertOcorrencias`. Exporte também uma variante que recebe o client admin, para o cron (BE-07).
- `listarContasDoMes(userId, ano, mes)`: gera e lista, com `situacao: 'pendente' | 'vencida' | 'paga' | 'cancelada'` derivada com `hojeSP()`.
- `criarContaUnica(userId, data)`, `atualizarConta(userId, id, data)` (só se `pendente`), `cancelarConta(userId, id)` (erro se `paga`).
- `pagarConta(userId, id, data)` → `pagarContaSchema.parse` + `rpcPagar`; `desfazerPagamento(userId, id)` → `rpcDesfazer`.
Aceite `hojeISO` opcional (default `hojeSP()`) para os testes.
