## Tarefa
1. Validators (exportar em `validators/index.ts`):
   - `contas-pagar.validator.ts`: `contaPagarInsertSchema` (`descricao` 1–500, `categoria` 1–100 default `'Contas'`, `valor` positivo, `vencimento` `yyyy-MM-dd`), `pagarContaSchema` (`pago_em` `yyyy-MM-dd` opcional, `banco` ≤100 nullable opcional);
   - `rendas.validator.ts` (`descricao`, `valor` > 0, `dia_recebimento` 1–31 opcional, `ativo`);
   - `orcamento.validator.ts` (`categoria` 1–100, `valor_planejado` ≥ 0);
   - `push-subscription.validator.ts` (`endpoint` URL https, `keys.p256dh`, `keys.auth` não vazios, `user_agent` opcional).
2. Repositories (exportar no barrel):
   - `contasPagarRepository`: `findByMonth(userId, competencia)`, `findById(id, userId)`, `create`, `update(id, data, userId)`, `upsertOcorrencias(rows)` (`onConflict: 'assinatura_id,competencia'`, `ignoreDuplicates: true`), `rpcPagar(id, pagoEm?, banco?)`, `rpcDesfazer(id)`;
   - `rendasRepository`, `orcamentoRepository` (CRUD por `userId`; orçamento com upsert em `user_id,categoria`);
   - `pushSubscriptionsRepository`: `upsertByEndpoint(userId, sub)`, `removeByEndpoint(userId, endpoint)`;
   - funções do cron, nomeadas `*ParaCron` e recebendo o client admin por parâmetro: `contasPendentesEntreParaCron(client, deISO, ateISO)`, `inscricoesDoUsuarioParaCron(client, userId)`, `removerInscricaoParaCron(client, id)`, `reservarLembreteParaCron(client, row)` (insert com `ignoreDuplicates`, retorna `true` só se inseriu).
   **Toda query de usuário filtra `.eq('user_id', userId)`.**
